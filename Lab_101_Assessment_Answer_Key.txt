1. Correct Answer: B
   Explanation: Bash Strict Mode (set -euo pipefail) ensures that if any 
   command fails (returns non-zero), the script terminates immediately. 
   This prevents "silent failures" where a script continues executing 
   despite errors, which could lead to an insecure or broken system state.

2. Correct Answer: A

   success exit code (0) even if `systemctl` or `awk` encounters an error

3. Correct Answer: C

   attacker. `cups` and `bluetooth` open network ports or hardware interfaces 
   that are unnecessary for a SOC analyst's core duties. Disabling them

SECTION 3: SHORT ANSWER & SCENARIO
-----------------------------------------------------------------------------

7. Scenario Answer:
   The script likely encountered a "non-zero exit code" from a command 
   inside a pipeline (e.g., `systemctl` returning an error or empty list). 
   Because `set -e` (exit on error) and `set -o pipefail` (fail on pipeline 
   error) were active, the script terminated immediately without printing 
   an error message. This is known as a "Silent Failure."

8. Attack Surface Reduction Answer:
   Attack Surface Reduction is the practice of minimizing the number of 
   vulnerabilities or entry points available to an attacker. By disabling 
   `ModemManager` on a workstation that does not use cellular modems, we 
   remove the software code that handles modem connections. If a vulnerability 
   were discovered in `ModemManager` tomorrow, our system would not be 
   affected because the service is not running or installed.

9. Critical Thinking Answer:
   You would be immediately locked out. Since the default policy is "deny 
   incoming," enabling the firewall activates that deny rule instantly. 
   Because no specific rule allowing SSH (port 22) exists yet, the firewall 
   drops all incoming SSH packets. Recovery would require physical console 
   access or out-of-band management (IPMI/iDRAC) to correct the rules.
