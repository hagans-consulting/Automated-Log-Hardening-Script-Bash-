# Automated Log Hardening Script (Bash)

The Project: Write a Bash script that automatically hardens your Ubuntu installation based on CIS Benchmarks (Center for Internet Security). The script should disable unused services, enforce password policies, and configure *ufw* (Uncomplicated Firewall).

# CLI Skills Practiced:

- Scripting: Variables, loops, conditional statements (*if/then*), and functions in Bash.

- File Permissions: Using *chmod*, *chown*, and *umask* to secure critical files like */etc/shadow* and */etc/passwd*.

- Firewall Configuration: Using *ufw* CLI to deny incoming traffic by default and allow only specific ports (e.g., SSH, HTTP).

- User Management: Using *usermod*, *passwd*, and editing */etc/sudoers* safely with *visudo*.

Security+ Alignment: Addresses Domain 3.0 (Security Architecture) and Domain 5.0 (Security Program and Oversight) regarding policy implementation.
